# Conflitos de uso da terra e vulnerabilidade ao fogo na APA do Rio Uberaba

Este repositório disponibiliza o script complementar utilizado para reprodução das principais etapas computacionais descritas no manuscrito:

**Conflitos de uso da terra e vulnerabilidade ao fogo na APA do Rio Uberaba**

O script apresenta uma versão simplificada e organizada dos procedimentos de análise, incluindo a preparação dos dados, identificação das áreas de conflito de uso da terra, processamento dos focos de calor, análise do gradiente espacial, correlações estatísticas e análise da precipitação.

## Dados

Os dados utilizados são provenientes de bases públicas indicadas no manuscrito. Os dados de entrada não são redistribuídos neste repositório e devem ser obtidos diretamente das respectivas fontes oficiais.

Entre as principais fontes utilizadas estão:

- Instituto Nacional de Pesquisas Espaciais (INPE) – Programa Queimadas;
- MapBiomas;
- Climate Hazards Center – CHIRPS;
- demais bases públicas especificadas no manuscrito.

## Código

O arquivo `script_reproducao_metodologia.py` contém uma versão complementar do código utilizado para reproduzir os procedimentos analíticos apresentados no estudo.

O script não corresponde ao código integral de desenvolvimento utilizado durante a pesquisa, mas reproduz as principais etapas metodológicas necessárias à compreensão dos procedimentos descritos no artigo.

## Reprodução

O código pode ser executado em ambiente Python ou adaptado para Google Colab, conforme as bibliotecas e fontes de dados utilizadas. Os caminhos dos arquivos de entrada devem ser ajustados de acordo com a estrutura de armazenamento do usuário.
